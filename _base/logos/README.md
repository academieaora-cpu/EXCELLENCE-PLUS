## Règles d'usage (charte graphique AORA)

- Logo toujours présent sur chaque visuel, **coin bas droit minimum**
- Taille minimale sur un post : **80 px de hauteur** → utiliser `100x100.png`
- Sur fond clair ou blanc → `excellence_plus_logo.png` (couleurs d'origine)
- Sur fond navy `#1B2D5C` → `aora_logo_blanc.png` pour AORA ; Excellence+ conserve ses couleurs
- **Zone de protection** : laisser un espace équivalent à la hauteur du logo tout autour — ne jamais coller le logo contre un bord
- Ne jamais étirer, déformer ou modifier les couleurs du logo
- Ne jamais placer le logo sur un fond qui compromet la lisibilité

## Pour Claude Code

Lors de la génération d'un brief visuel, référencer systématiquement :
